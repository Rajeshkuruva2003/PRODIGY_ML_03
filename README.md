## 📖 About the Project

This project applies machine learning techniques to predict housing prices. It involves data preprocessing, exploratory data analysis (EDA), model training, and evaluation. The model is trained on historical housing data and is capable of making price predictions for new/unseen data.

### Features:
- Data preprocessing and cleaning
- Exploratory data analysis and visualization
- Feature selection and engineering
- Model training using Linear Regression, Random Forest, and XGBoost
- Model evaluation using metrics like RMSE and R²
- Web interface for user input and predictions (optional with Flask/Streamlit)
